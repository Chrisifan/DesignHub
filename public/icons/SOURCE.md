Copied exact SVG bytes from package/icons. more-horizontal.svg is the original ellipsis.svg under a compatible local filename. unlock.svg is the original lock-open.svg. No glyphs were redrawn. Assets are served locally; the application makes no icon/font network requests.

The existing G03 plan specifies Lucide as the icon direction; this framework uses a small static subset rather than adding another runtime package. The GitHub raw endpoint encountered TLS hostname validation failure; the npm registry artifact was fetched with normal certificate validation.
