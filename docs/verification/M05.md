## Task 1: finite scene schema and transformations

### Pre-implementation checklist

| ID | Failure prevented | Verification |
| --- | --- | --- |
| C01 | Resizing mutates a persisted layer or accepts impossible sizes. | `resizeLayer` returns a fresh layer and rejects zero, negative, and non-finite sizes. |
| C02 | Canvas-library objects leak into the project scene. | The scene round trip uses only DesignHub's finite JSON schema and rejects invalid data. |
| C03 | Locked or hidden layers behave as deleted layers. | Updates preserve state; interaction helpers separately expose locked/visible behavior. |
| C04 | View zoom changes export/document pixels. | Viewport state is not included in scene serialization. |
| C05 | Layer order/multi-selection become inconsistent after edits. | Reordering and selection tests retain stable ids and valid order. |
