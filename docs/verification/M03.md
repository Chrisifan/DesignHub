## Task 3: Portfolio source selection policy

Task 3 is intentionally limited to the pure selection contract in `src/features/designers/portfolio.ts`. It validates explicit rights confirmation and source IDs, then returns only selected IDs in input order. It performs no URL/path parsing, fetching, upload, image decoding, persistence, model invocation, or UI changes.
