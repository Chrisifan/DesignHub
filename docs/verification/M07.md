## 2026-10-15 Registered batch-result symlink boundary

A persisted completed result could be replaced with an external symlink after execution. Previous handlers checked only lexical containment and registration (reveal did not require registration), then followed the changed path. A shared async resolver now checks the exact persisted item `resultPath`, lexical output-root containment, an explicit `.png`/`.webp`/`.jpg`/`.jpeg` MIME allowlist, `lstat` regular-file/non-symlink status, and containment of the resolved file inside the resolved output root before read/open/reveal/import. Unusable results return null/false without external callbacks. Import no longer labels every unknown extension as JPEG. `openOutput` retains its directory-opening behavior.
