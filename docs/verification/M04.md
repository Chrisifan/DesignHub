## Task 1: explicit brief confirmation

The implemented slice is limited to `confirmBrief` in `src/features/projects/brief.ts`. It accepts a typed draft and an explicit confirmation flag, validates the name and workspace, trims the returned name, and returns a new object. It does not create project directories, call M02 storage, persist drafts, invoke models, build UI, or add dependencies.
