# M05 组合画布 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付图像、文字、基础形状、裁切遮罩和可恢复编辑，不破坏修订历史。

**Architecture:** 场景数据独立于画布库；视口和选择为临时 UI 状态，编辑批次调用 M04 commitRevision。后台处理和分级预览降低大图交互阻塞。

**Tech Stack:** G05 Konva/react-konva 或 Fabric 候选；G06 解码与系统字体路径；准确依赖版本在研究采用记录中锁定。

**Spec:** [首版架构](../specs/2026-09-08-designhub-v1-design.md)，[UI 说明书](../../product/APPLICATION-GUIDE-FOR-UI.md)，[UI 基础规范](../../product/UI-FOUNDATIONS.md)，[主计划](2026-09-08-designhub-v1.md)。

## Global Constraints

- 画布运行于 Electron 的隔离 renderer；通过 platform 提交版本，不能直接导入 SQLite、文件系统或 Sharp。R01/R02 需重新测 Electron 的输入延迟和总进程内存，Tauri 数据仅作历史参考。
- P06 布局只参考 Figma allowlist 中的 `39:14262`：宽屏允许导航、画布与检查器共存，1024–1279px 将低优先级检查器转为抽屉；透明窗口材质不能污染画布色彩判断。

- 先调研成熟框架或第三方库，再写对应功能实现；未核验候选不等于选型。
- 按模块先写测试用例和 checklist，再实现并对照验证；改到已验证模块必须记录影响并回归。
- 所有自写函数遵守用户“箭头函数”要求；不能默许原生代码例外。
- 核心浏览、编辑、历史、检索、导出、备份离线可用；云请求不在重连后静默提交。
- 无平台账户；提供方密钥只存系统安全存储，不进项目、包、备份、日志。
- 主计划的其余全局约束和模块记录协议全部适用。先创建 `docs/verification/M05.md`，再实现下列目标文件。
- 下列代码是计划中的行为测试及核心规则片段；完整用例还必须覆盖每项验收场景，不以片段替代模块交付。

```ts
export const resizeLayer = (
  layer: { id: string; width: number; height: number },
  size: { width: number; height: number },
) => {
  if (!Number.isFinite(size.width) || !Number.isFinite(size.height)
    || size.width <= 0 || size.height <= 0) throw new Error('INVALID_SIZE');
  return { ...layer, ...size };
};
```

- [ ] **Step 3：实现最小完整用例。**

```ts
export const isRegionInside = (
  region: { x: number; y: number; width: number; height: number },
  image: { width: number; height: number },
) => Object.values({ ...region, imageWidth: image.width, imageHeight: image.height }).every(Number.isFinite)
  && region.x >= 0 && region.y >= 0 && region.width > 0 && region.height > 0
  && region.x + region.width <= image.width && region.y + region.height <= image.height;
```

实现裁切可见范围、非破坏遮罩、临时像素选区和清除/取消。一次拖动或输入提交形成批次；撤销/重做管理当前编辑记录，不删已保存历史。草稿周期落盘，保存成功才显示已保存。旧版继续走 M04 分支；外接盘拔出保持内存编辑并显示恢复入口。
