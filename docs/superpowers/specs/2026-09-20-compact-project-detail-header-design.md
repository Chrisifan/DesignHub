# 项目详情紧凑头部设计

## 目标

继续压缩项目详情页顶部的封面与摘要区域，在桌面标准尺寸下将整个头部控制在约 `330px` 高度，同时保留当前上下分区、信息层级、操作能力和响应式布局。

## 布局

- 保持“上方封面、下方项目摘要”的结构，不改为左右分栏，也不把标题叠到封面上。
- 桌面端封面目标高度为 `168px`，摘要区目标高度约 `150px`，完整头部约 `330px`。
- 头部圆角、边框和现有材质保持不变。
- 页面头部与下方内容的间距同步收紧，避免压缩头部后仍留下过多空白。

## 信息密度

- 摘要区内边距从当前宽松尺寸压缩到约 `16px 20px`。
- 项目标题使用约 `30–32px` 字号，保留当前字重和截断策略。
- 状态、标题、简介之间减少垂直间距。
- 简介最多显示一行，溢出显示省略号；无简介时仍保留一行高度，避免布局跳动。
- 设计署名与本地保存状态继续在同一行展示，并缩小其上方间距。
- “打开画布”和“导出交付”按钮保持现有可点击尺寸，仅压缩按钮组与内容间距。

## 响应式行为

- 宽屏和中等宽度沿用双列摘要结构：左侧信息，右侧操作。
- `720px` 以下继续切换为单列摘要和可伸展按钮，封面高度维持约 `168px`，不进一步压缩可读性。
- 不引入横向滚动或文本覆盖。

## 验收

- 在 `1440 × 1000` 和 `1024 × 900` 视口下，项目详情头部高度不超过 `340px`。
- 封面可见高度位于 `160–176px`。
- 简介始终占据一行，长文本省略，无简介时布局高度一致。
- 标题、状态、署名、保存状态和两个操作按钮均保持可见、可访问。
- 现有项目详情单元测试、响应式 E2E、类型检查和构建继续通过。
