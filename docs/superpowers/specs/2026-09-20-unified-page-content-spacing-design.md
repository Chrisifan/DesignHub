# 页面内容区统一边距设计

## 目标

统一 DesignHub 普通内容页的页面级内部边距，消除项目列表、项目详情、设计师、素材库、品牌包、任务和连接等页面之间的视觉跳动，同时保持画布等沉浸式页面的全屏布局。

## 范围

纳入统一规则的页面：

- 项目列表
- 项目详情
- 设计师库
- 素材库
- 品牌包
- 任务、连接和其他使用 `.page-content` 的普通内容页

不纳入统一规则的界面：

- 画布工作区
- 欢迎页
- 抽屉
- 弹窗
- 页面内部卡片、面板和工具栏的局部间距

## 布局规则

在 `src/app/styles/tokens.css` 中定义共享页面间距 token，由普通页面容器统一消费：

| 视口范围 | 顶部 | 水平 | 底部 |
| --- | ---: | ---: | ---: |
| 宽屏（≥ 1440px） | 28px | 32px | 24px |
| 标准窗口（1280–1439px） | 24px | 28px | 20px |
| 紧凑窗口（561–1279px） | 20px | 24px | 16px |
| 窄窗口（≤ 560px） | 16px | 16px | 16px |

`.page-content` 使用共享 token 设置 padding。项目详情页和设计师库移除页面级硬编码 padding，继承同一规则。它们仍可保留与页面外边距无关的布局属性，例如网格、最大宽度、内部滚动和模块间距。

## 页面行为

- 保留普通页面由 `.page-content` 负责纵向滚动的现有约定。
- 保留设计师页的内部面板滚动，不改变其高度与 overflow 结构。
- 保留现有页面最大宽度；不额外限制卡片列表空间。
- 不修改卡片宽度、网格 gap、详情模块内部 padding 或工具栏尺寸。
- 项目详情页不再使用最高 56px 的特殊水平留白，与其他普通页面保持一致。

## 实现位置

- `src/app/styles/tokens.css`：新增共享页面间距 token 及响应式覆盖。
- `src/app/styles/studio.css`：`.page-content` 改为消费共享 token，现有断点不再重复声明具体 padding。
- `src/app/studio/project-detail.css`：移除项目详情页页面级 padding 覆盖。
- `src/app/studio/persona.css`：移除设计师库页面级 padding 覆盖。
- `tests/integration/layout-contract.test.ts`：增加统一间距的布局契约测试。

## 兼容性与验证

- 旧页面只要使用 `.page-content`，会自动获得一致的响应式留白。
- 特殊页面通过不使用 `.page-content` 或自身既有容器保持原布局。
- 测试应验证共享 token 的四组取值、普通容器对 token 的使用，以及项目详情和设计师页不再硬编码页面 padding。
- 运行布局契约测试、相关页面测试、类型检查和构建，确认无横向溢出、滚动所有权变化或页面高度回归。
