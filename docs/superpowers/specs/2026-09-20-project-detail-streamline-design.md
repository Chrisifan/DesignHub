# 项目详情页精简设计

## 目标

让项目详情页以设计稿列表为核心，减少重复状态、存储信息和无意义的项目侧栏。

## 布局

- 封面左下角只保留一组紧凑信息，同时显示项目状态和设计稿数量，例如“进行中 · 2 份设计稿”。
- 封面下方摘要仅保留项目标题、简介和设计署名。
- 删除摘要右侧的大号“打开画布”和“导出交付”按钮。
- 删除所有“本地保存”“仅当前会话”和设计稿卡片中的“本地/未保存”标签。
- 删除下方右侧的项目上下文、设计协作和品牌快照栏。
- 设计稿列表占满页面可用宽度，保持现有卡片交互；点击具体设计稿仍进入对应画布。
- “新建设计稿”从列表标题区域移到顶部面包屑右侧工具栏，仅可写项目显示。
- 顶部工具栏现有的交付、继续编辑、重命名、复制和归档操作保持不变。

## 状态和空态

- 状态继续区分进行中、已归档和未保存草稿。
- 数量以实际 `documents.length` 显示，避免 metadata 计数与列表不一致。
- 没有设计稿时保留现有空态；可写项目仍可通过顶部工具栏创建第一张设计稿。
- 无设计师时继续显示“未设置设计师”。

## 验证

- 头部组合状态同时包含状态和设计稿数量。
- 页面不存在本地保存文本、头部动作按钮和项目相关信息侧栏。
- 设计稿区域为全宽单栏布局容器。
- 顶部工具栏显示“新建设计稿”，点击后打开现有新建设计稿流程。
- 只读项目不显示新建设计稿入口。
