# 项目内新建设计稿设计

## 目标

将项目详情页中含义狭窄的“新建尺寸”入口改为“新建设计稿”，让用户可以在现有项目中创建一份独立空白设计稿，也可以继续从已定稿文档派生尺寸变体。

## 交互

- 项目详情页“设计文档”区域的主操作改为“新建设计稿”。
- 点击后打开“新建设计稿”对话框，默认选择“空白设计稿”。
- 对话框提供两种创建方式：
  - **空白设计稿**：填写名称、宽度和高度后创建独立文档，不要求项目中已有定稿。
  - **尺寸变体**：选择一个已定稿源文档，填写名称、宽度和高度后创建关联文档，并复用现有 scene 缩放逻辑。
- 项目没有任何已定稿文档时，“尺寸变体”不可选，并明确提示需要先定稿；空白设计稿仍可创建。
- 创建成功后关闭对话框，新文档出现在项目详情列表中并成为活动文档，但不自动进入画布。

## 数据与边界

- 不新增 IPC 或持久化格式，继续通过 `updateProjectMetadata` 写入项目 `documents`。
- 空白设计稿只包含 `id`、`name`、`width`、`height` 和 `finalizedRevisionId: null`，不带来源字段。
- 尺寸变体额外包含 `sourceDocumentId` 和 `sourceRevisionId`；若源 revision 含 scene，则缩放后保存为新文档 scene。
- 文档卡片沿用现有规则：只有带来源字段的文档显示为“衍生稿”。
- 只读工作区继续隐藏创建入口。

## 错误处理

- 名称为空、尺寸不是正数或尺寸变体未选择有效定稿源文档时，不提交 metadata。
- scene 转换失败时保留已经创建的尺寸变体，并提示它已作为空白稿创建。
- metadata 更新失败时不关闭对话框，也不伪造本地文档。

## 测试

- 项目详情页显示“新建设计稿”，只读状态隐藏该入口。
- 无定稿项目可以创建空白设计稿。
- 空白设计稿不携带来源字段。
- 尺寸变体仅能从已定稿文档创建，并保留现有 scene 缩放行为。
- 创建结果显示在项目文档列表中。
