# 项目详情页布局重构设计

## 目标

参照用户提供的项目控制台设计图，重构项目详情页的信息层级和响应式布局。新页面只展示当前代码库已有的真实项目、文档、设计师、品牌快照和操作能力，不新增虚假的生命周期、存储占用、算力或版本统计数据。

## 架构

- 从 `Studio.tsx` 抽出独立的 `ProjectDetailPage` 组件，由 `Studio` 负责提供项目数据和操作回调。
- `ProjectDetailPage` 负责项目详情的页面结构、状态映射和响应式展示，不直接访问桌面 API。
- 项目管理、设计师切换、贡献者切换、新建尺寸、打开文档、导出交付等数据流继续由 `Studio` 持有。
- 组件使用现有 `Project`、`PersonaProfile`、`ProjectCoverImage`、`DesignerHero`、按钮、选择器和空状态组件，不另建平行的数据模型。

## 页面结构

### 顶部主视觉

- 使用项目封面渲染宽幅 Hero，保持居中裁切并沿用默认封面回退逻辑。
- Hero 显示文档数量，并在存在可打开文档时提供“打开画布”主操作。
- 不实现参考图中的“更换封面”，因为当前项目详情没有既有的封面更新流程。

### 项目摘要

- 展示项目状态、名称、简介、设计师署名和保存位置。
- 提供现有的“打开画布”和“导出交付”操作。
- 项目简介在摘要区完整展示，移除页面底部重复的设计简报区域。
- 无简介时保留稳定结构并显示明确的空状态文案。

### 主内容

- 宽窗口使用约 `2fr / 1fr` 的左右布局。
- 左侧为设计文档区，包含文档数量、新建尺寸按钮和文档卡片。
- 文档卡片展示已有文档名称、尺寸、项目保存状态和可推导的版本状态。
- 文档状态映射：
  - `finalizedRevisionId` 存在：已定稿。
  - `sourceRevisionId` 存在且未定稿：衍生稿。
  - 其他持久化文档：进行中。
  - 会话预览文档：未保存。
- 无文档时继续使用现有空状态，且不显示无效的打开画布操作。

### 右侧信息栏

- 项目上下文：活跃设计师版本、项目状态、文档数量、内容保留方式。
- 设计协作：展示当前设计师、版本署名，并在可写项目中保留设计师切换和贡献者勾选功能。
- 品牌快照：仅在现有 `brandSnapshot` 通过品牌结构校验时展示名称、版本、色板、字体和语气；无效或缺失时显示“未附加品牌包”。
- 不展示生命周期完成度、磁盘占用、算力状态、虚构里程碑或不存在的版本快照数量。

## 操作与权限

- Hero 主操作打开当前主文档；每张文档卡片打开自身对应文档。
- 顶部工具栏继续保留重命名、复制、归档和其他已有管理操作。
- 可写项目显示新建尺寸、设计师切换和贡献者设置。
- 只读项目只展示数据，不显示写操作。
- 导出交付继续走现有回调，不改变交付数据流。

## 响应式与视觉

- 视觉方向采用参考图中的深色控制台式层级：宽幅主视觉、紧凑状态标签、分区面板和清晰的主次操作。
- 继续使用项目现有颜色、字体、边框、玻璃材质和间距 token，不复制参考图中的品牌标识或不存在的系统状态。
- 大于约 `1100px` 时使用双栏主内容；更窄窗口改为单列，右侧信息栏移动到文档区之后。
- `720px` 以下操作区允许换行，文档卡片变为单列。
- 页面只保留自身纵向滚动，不产生文档级横向滚动。
- 支持深色、浅色和降低透明度模式。

## 错误与空状态

- 封面资产读取失败时由 `ProjectCoverImage` 回退默认封面。
- 无简介时显示本地化空状态文本，不隐藏摘要区域。
- 无设计师时显示“未设置设计师”，不创建占位设计师或伪造风格信息。
- 无品牌快照或快照结构无效时显示“未附加品牌包”。
- 无文档时显示现有“暂无设计文档”空状态。

## 测试

- 组件测试验证 Hero、摘要、文档区和右侧信息栏均使用现有项目数据。
- 组件测试覆盖有/无封面、简介、设计师、品牌快照和文档。
- 组件测试覆盖可写与只读权限下的操作差异。
- 组件测试验证主操作与文档卡片传递正确文档 ID。
- Studio 集成测试继续验证重命名、复制、归档、设计师切换、贡献者设置和新建尺寸。
- E2E 验证 `1440px` 双栏、`1024px` 单栏、无横向溢出以及主操作可打开画布。
- 运行相关单元测试、集成测试、类型检查、Lint 和构建。

## 边界

- 不增加新的项目持久化字段。
- 不增加封面更新流程。
- 不生成文档缩略图或生命周期统计。
- 不修改画布工作台、对话生成链路或交付格式。
- 不移除顶部工具栏中已有的项目管理能力。
