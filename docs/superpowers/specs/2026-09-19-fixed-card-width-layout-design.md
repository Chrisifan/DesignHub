# 固定宽度卡片布局设计

## 目标

项目、设计师、素材库等卡片型资源页面在宽窗口下保持稳定、易扫视的卡片尺寸，避免现有等分网格把卡片横向拉伸。

## 布局规则

- 项目、设计师和素材库的网格模式统一使用约 `280px` 的固定卡片列宽。
- 卡片容器按可用宽度自动增加列数，所有卡片左对齐排列，末行不拉伸。
- 页面保留现有卡片视觉比例、间距、悬浮态、选中态和操作行为。
- 窄窗口无法容纳固定宽度时退化为单列，卡片宽度不超过容器可用宽度，避免横向溢出。
- 素材库列表模式保持现有全宽行布局。
- 详情面板、设置页面、任务列表和画布候选稿不纳入本次调整。

## 实现范围

- 调整项目卡片集合的网格列定义。
- 调整设计师档案库及设计师选择类卡片集合的网格列定义。
- 调整素材库网格模式的列定义。
- 优先复用共享 CSS 自定义属性表达统一卡片宽度，避免各页面产生不同尺寸。
- 保留现有响应式断点，仅将卡片列从弹性等分改为固定宽度自动换行。

## 验收标准

- 宽窗口中卡片宽度不会随窗口继续增大。
- 同一类卡片在各行宽度一致，末行卡片不会被拉伸。
- 窄窗口中没有横向滚动，卡片可缩至容器宽度。
- 素材库列表模式、卡片交互和页面功能没有回归。
- 自动化测试覆盖项目、设计师和素材网格的固定列宽契约。
