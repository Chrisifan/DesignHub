# 项目卡片内容对齐设计

## 目标

项目卡片无论是否包含简介或设计师，都保持封面、标题、简介、设计师署名和来源信息的统一位置。简介最多显示两行，超出部分以省略号截断。

## 设计

- 项目卡片始终渲染简介段落，不为无简介项目显示额外占位文案。
- 简介段落使用独立的语义化样式类，预留两行文本的最小高度。
- 简介采用两行 CSS line clamp；长文本在第二行末尾截断并显示省略号。
- 网格视图的项目卡片使用明确的“封面 + 正文”两行布局，避免 Grid 拉伸后原生按钮把较矮内容垂直居中；列表视图继续保持横向布局。
- 正文使用纵向布局，标题和简介从顶部依次排列，设计师元信息固定在正文底部。
- 设计师元信息区域固定保留 `24px` 高度。有设计师时显示 `24px` 头像；无设计师时只显示“未设置设计师”，不添加虚假占位头像。
- “本地”或“未保存”来源信息与设计师信息在统一高度内垂直居中。
- 网格视图与列表视图沿用同一简介规则，不改变标题、封面、设计师署名或来源信息。
- 空简介仍保留空白区域，但不会向辅助技术暴露无意义的占位字符。

## 测试

- 组件测试验证无简介项目仍渲染简介区域。
- 组件测试验证简介区域使用专用样式类，供两行布局稳定生效。
- 样式回归验证专用类包含两行高度和两行截断规则。
- 样式回归验证卡片使用显式布局、正文为纵向布局、设计师元信息区固定为 `24px`。
- 浏览器回归测试同时渲染有/无简介、有/无设计师的卡片，验证封面顶部、标题顶部、设计师区域顶部和设计师区域高度一致。
- 运行相关 Studio 测试、类型检查、Lint 和构建。

## 边界

- 不新增“暂无简介”等可见文案。
- 不为无设计师项目添加占位头像。
- 不修改项目简介的数据模型或持久化逻辑。
- 不调整卡片宽度、封面比例及其他卡片内容。
