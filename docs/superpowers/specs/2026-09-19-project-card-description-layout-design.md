# 项目卡片简介布局设计

## 目标

项目卡片无论是否包含简介，都保留一致的简介区域，避免标题、设计师署名和来源信息因简介缺失而上下错位。简介最多显示两行，超出部分以省略号截断。

## 设计

- 项目卡片始终渲染简介段落，不为无简介项目显示额外占位文案。
- 简介段落使用独立的语义化样式类，预留两行文本的最小高度。
- 简介采用两行 CSS line clamp；长文本在第二行末尾截断并显示省略号。
- 网格视图与列表视图沿用同一简介规则，不改变标题、封面、设计师署名或来源信息。
- 空简介仍保留空白区域，但不会向辅助技术暴露无意义的占位字符。

## 测试

- 组件测试验证无简介项目仍渲染简介区域。
- 组件测试验证简介区域使用专用样式类，供两行布局稳定生效。
- 样式回归验证专用类包含两行高度和两行截断规则。
- 运行相关 Studio 测试、类型检查、Lint 和构建。

## 边界

- 不新增“暂无简介”等可见文案。
- 不修改项目简介的数据模型或持久化逻辑。
- 不调整卡片宽度、封面比例及其他卡片内容。
