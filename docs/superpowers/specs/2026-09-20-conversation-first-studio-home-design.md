# 对话优先的应用首页重构设计

## 目标

将 DesignHub 的应用入口重构为“项目浏览 + 首轮对话创建”的首页：左侧展示当前工作区项目，右侧通过文字和图片发起设计需求；发送后自动创建项目和默认文档，进入画布并开始现有的设计分析流程。

新首页保留工作区切换、主题和语言切换，移除常驻左侧全局导航与底部状态栏。设计师、素材库、品牌包、模型连接等低频入口收纳到右上角用户头像菜单。

## 设计原则

- 对话是创建项目的默认入口，但不移除现有手动新建项目能力。
- 首轮对话自动创建的项目使用明确、可预测且本地化的名称。
- 用户输入、图片和设计师选择在任何失败状态下都不能无提示丢失。
- 自动创建项目后沿用现有画布、分析线程、候选稿和定稿链路，不建立第二套生成流程。
- 项目可不绑定设计师；选择设计师是首页上的可选操作。
- 顶部和左侧不使用贯穿页面的分割线，应用背景在视觉上连续。

## 信息架构

### 顶部控制区

顶部控制区不表现为独立、有分割线的传统 header，而是直接悬浮在应用连续背景上：

- 左侧：DesignHub 品牌标识、当前工作区切换。
- 右侧：主题切换、语言切换、用户头像。
- 工作区切换继续复用现有工作区选择弹窗和最近工作区能力。
- 主题和语言保留直接入口，不放入头像菜单重复展示。

### 首页主体

首页使用 `30 / 70` 双栏布局：

- 左侧为项目悬浮面板。
- 右侧为欢迎语、首轮对话输入框、建议提示和设计师灵感列表。
- 应用最小窗口宽度为 1024px，因此桌面范围内始终保持双栏。

左侧项目面板包含：

- 现有“进行中 / 已归档 / 全部项目”分类。
- 现有项目搜索。
- 紧凑项目列表，展示封面、名称、设计稿数量和更新时间。
- 列表内部滚动，项目面板在首页可视区域内保持稳定。
- 点击项目继续进入现有项目详情页。

右侧首轮对话区域包含：

- 本地化欢迎语。
- 必填文字输入。
- 最多沿用现有对话附件数量限制的图片附件。
- 模型连接状态。
- 发送按钮和少量本地化提示词建议。
- 发送期间禁用重复提交。

### 设计师灵感列表

设计师列表位于参考布局“需要灵感？”区域，横向滚动展示当前可用、未归档的设计师：

- 默认无选择，自动创建的项目不携带设计师风格。
- 点击设计师后单选并显示清晰的图标与文字状态。
- 再次点击已选设计师可取消选择。
- 选中项只影响下一次从首页自动创建的项目。
- 发送成功后重置选择；创建失败时保留选择。
- 末尾提供“查看全部”，进入完整设计师页面。
- 支持触控板、鼠标滚轮横向映射和键盘聚焦。

### 用户头像菜单

头像菜单收纳原左侧导航和其他低频操作：

- 创作：首页、设计师、素材库、品牌包。
- 模型：模型连接、模型任务。
- 管理：导出交付、工作区管理、设置。
- 操作：新建空白项目、导入项目包。

“新建空白项目”继续打开现有新建项目抽屉，保留现有的名称、目标、封面、尺寸和设计师字段，本轮不新增品牌包选择。菜单支持点击外部关闭、`Escape` 关闭、正确焦点顺序和当前页面标记。

从菜单进入资源或管理页面时，页面使用完整内容区；通过顶部品牌或菜单“首页”返回双栏首页。项目详情保留项目上下文操作，画布保留自身工具栏。

## 自动创建与首轮对话流程

### 默认项目数据

首轮对话创建的项目使用：

- 中文基础名称：`未命名项目`。
- 英文基础名称：`Untitled project`。
- 默认文档名称：中文 `主海报`，英文 `Main poster`。
- 默认尺寸：`1080 × 1440`。
- 默认无品牌包。
- 默认无设计师；只有用户在首页选择设计师时才保存完整设计师快照。
- 默认封面使用现有项目默认封面机制。

项目命名由独立纯函数处理。它读取当前工作区项目名称，基础名称可用时直接返回；重名时从 `(1)` 开始寻找第一个可用编号，例如 `未命名项目 (1)`、`未命名项目 (2)`。切换语言只影响后续创建，不重命名已有项目。

### 提交流程

发送首条消息前依次验证：

1. 输入文字非空；图片为可选附件。
2. 当前工作区存在且为可写模式。
3. 模型连接可用。
4. 当前没有正在进行的首页创建请求。

验证通过后：

1. 固化本次消息、附件和可选设计师选择，生成唯一项目名、项目 ID 请求和文档 ID。
2. 调用现有 `createProjectContainer` 创建项目与默认文档；设计师被选中时提交 `activeDesignerVersionId` 和不可变 `designerSnapshot`。
3. 将新项目插入项目列表，设置为当前项目和当前文档，并立即进入现有画布。
4. 通过一次性 `pendingHomeConversation` 把文字和附件交给对应 `Workbench`。
5. `Workbench` 挂载后消费该上下文，打开分析面板并调用现有 `onSubmitConversation`。
6. 消费成功后清空首页文字、附件和设计师选择，避免再次进入画布时重复提交。

首页不自行保存附件或组装权威生成上下文。附件仍由现有对话任务主进程链路保存为受管资产，项目 brief、当前画布和完整设计师快照仍由主进程读取和验证。

### 失败状态

- 工作区只读：输入框可浏览但发送和新建操作禁用，显示只读说明。
- 模型未连接：点击发送只提示连接模型，不创建项目。
- 项目创建失败：停留首页，保留文字、图片和设计师选择，允许重试。
- 项目创建成功但分析提交失败：保留已创建项目并停留画布，现有分析区域显示失败和重试；不回滚或删除项目。
- 重复点击：创建请求期间发送按钮进入忙碌状态，后续点击不发起第二次请求。
- 页面卸载或附件被移除时，正确释放本地预览 URL。

## 组件与代码边界

为避免继续扩大 `Studio.tsx`，拆分以下单一职责组件：

- `StudioHome.tsx`
  - 组合首页双栏布局。
  - 管理首轮文字、附件、设计师选择和提交状态。
  - 通过 props 接收项目数据与创建回调，不直接调用桌面 API。
- `HomeProjectPanel.tsx`
  - 项目分类、搜索、紧凑列表和内部滚动。
- `HomeConversationComposer.tsx`
  - 首轮文字、附件、模型状态和发送按钮。
- `HomeDesignerRail.tsx`
  - 设计师横向列表、单选/取消和查看全部。
- `StudioUserMenu.tsx`
  - 头像菜单、分组导航和手动操作。
- `auto-project-name.ts`
  - 不依赖 React 或桌面 API 的本地化唯一名称函数。

`Studio.tsx` 保留应用级编排职责：加载工作区项目与设计师、执行项目创建、切换 surface、把一次性首轮上下文传递给 `Workbench`，并继续挂载现有资源页、项目详情和画布。

`WindowBar.tsx` 扩展头像菜单挂载点，并调整为无分割线的连续顶部控制区。现有原生窗口拖动区域和原生窗口控制安全区必须保留。

`Workbench.tsx` 增加一次性首页首轮上下文输入。它复用现有 `submitPromptRequest` 行为，不另建简化任务接口；上下文被成功消费后通过回调通知 `Studio` 清除。

## 视觉与响应式规则

- 应用主体使用现有主题 token，并增加克制的点阵背景。
- 项目面板、对话输入框、头像菜单和设计师卡片使用统一的半透明磨砂玻璃 token。
- 顶部区域没有底部分割线，项目面板右侧没有贯穿式边线。
- 1024px 到常用桌面宽度保持双栏；左栏使用约 30% 且带最小、最大宽度，右栏占剩余空间。
- 左侧项目列表内部滚动，右侧首页内容纵向滚动，设计师列表横向滚动。
- 文本、控件和卡片在中英文下不能溢出；长项目名使用单行省略。
- 选中、禁用、忙碌和错误状态同时使用图标或文字，不仅依赖颜色。
- 尊重 `prefers-reduced-motion` 和 `prefers-reduced-transparency`。

## 数据兼容与边界

- 不修改项目持久化格式，自动创建仍调用现有项目容器 API。
- 不修改现有分析任务、候选稿、revision 或定稿数据结构。
- 不引入项目级长期聊天历史。
- 不根据首条需求自动推断文档尺寸；本轮固定使用 `1080 × 1440`。
- 不自动生成项目封面；没有封面时继续使用现有默认封面。
- 不在首页直接生成设计稿；首页负责创建项目并启动首次分析，后续生成仍在画布分析面板中由用户触发。

## 测试与验收

### 单元测试

- 中文和英文基础名称生成。
- 已存在基础名称及多个编号时选择第一个可用 `(n)`。
- 默认无设计师；选中、取消设计师及成功后重置。
- 项目分类、搜索和点击打开项目。
- 头像菜单分组导航、外部关闭和 `Escape` 关闭。
- 首页附件添加、删除和预览 URL 释放。

### 集成测试

- 首条消息创建项目和 `1080 × 1440` 默认文档。
- 自动创建项目使用当前语言名称。
- 附件和选中设计师快照进入新项目及首次分析。
- 创建成功后进入对应项目画布并只提交一次分析。
- 只读、模型未连接、创建失败和重复点击不创建无效项目。
- 分析提交失败时保留项目并可重试。
- 工作区切换后项目列表、命名去重范围和设计师数据切换到新工作区。

### UI 与布局测试

- 标准窗口下首页保持 30 / 70 双栏。
- 顶部和左侧不存在贯穿式分割线。
- 左侧项目列表和设计师横向列表具有独立滚动行为。
- 明暗主题、中文和英文均正常显示。
- 头像菜单可访问所有被迁移的入口。
- 手动新建项目抽屉仍可使用。
- 项目详情、资源页和画布原有核心行为没有回归。
