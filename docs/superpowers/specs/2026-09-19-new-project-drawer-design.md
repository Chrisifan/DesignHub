# 新建项目抽屉设计

## 目标

移除项目列表下方重复的“下一次创作”入口，将顶部工具栏的“新建项目”作为唯一入口，并把现有整页创建流程改为右侧抽屉。

## 交互流程

- 项目列表仅保留顶部工具栏中的“新建项目”按钮。
- 点击按钮后，项目列表保留在背景，右侧打开标准抽屉。
- 抽屉标题为“新建项目”。
- 抽屉内容只包含：
  - 项目名称
  - 设计目标
  - 设计师选择，包含“不设置设计师”
  - 文档尺寸
- 不展示设计师完整档案预览。
- 抽屉底部固定显示“取消”和“创建项目”；没有可写工作区时沿用现有“创建预览”语义和提示。
- 项目名称为空时创建按钮禁用。
- 点击关闭、取消、遮罩或按 Escape 关闭抽屉，未提交草稿继续保留；再次打开可继续编辑。
- 创建成功后关闭抽屉，并沿用现有逻辑进入新项目详情。
- 从设计师页面执行“用于新建”时打开同一个抽屉，并预选该设计师。

## 组件结构

- 将 `NewDesignPage` 的表单内容收敛为抽屉可复用的 `NewDesignForm`，表单保持唯一状态来源。
- `Studio` 管理抽屉开关、草稿状态与创建操作。
- 创建按钮位于 `Drawer` 的固定 footer，通过表单 `id` 提交内容区中的表单。
- 移除 `new-design` 整页 surface、面包屑返回按钮以及对应页面布局和设计师档案样式。
- 保留现有项目创建、持久化、无设计师创建、尺寸选择、焦点恢复及错误提示逻辑。

## 视觉与可访问性

- 复用现有标准抽屉样式和焦点陷阱，不新增独立遮罩系统。
- 抽屉使用紧凑宽度，但需容纳设计师选择列表和表单标签。
- 内容区域独立滚动，footer 始终可见。
- 打开后聚焦项目名称输入框；关闭后焦点返回触发“新建项目”的按钮。
- 抽屉保留 `role="dialog"`、标题关联、Escape 关闭和键盘 Tab 循环行为。

## 删除内容

- 删除项目列表底部“下一次创作，从这里开始”整块内容。
- 删除 `.creation-note` 相关样式。
- 删除完整设计师档案预览及 `.new-design-dossier` 相关布局。
- 删除仅服务于整页新建流程的返回按钮和页面 surface 分支。

## 测试与验收

- 项目列表中只存在一个“新建项目”入口，不再出现“下一次创作”或“开始创作”。
- 点击顶部入口会打开“新建项目”抽屉，项目列表仍挂载在背景。
- 抽屉包含四项表单内容，不包含完整设计师档案。
- 创建按钮位于抽屉 footer，名称为空时禁用。
- 关闭再打开时草稿保留，焦点返回顶部入口。
- “用于新建”会打开同一个抽屉并预选设计师。
- 持久化项目和会话预览创建行为保持不变。
- 相关单元测试、类型检查、Lint 和构建通过。
