# 项目封面选择设计

## 目标

新建项目时允许用户选择本地图片作为项目封面。未选择图片、旧项目缺少封面信息、或自定义封面无法读取时，统一使用内置默认封面。用户提供的 `codex-clipboard-51bbecfe-49e4-466d-9a2f-d55f2c68fef3.png` 作为默认封面的视觉源文件。

本轮只覆盖新建项目流程和项目列表卡片展示，不增加项目创建后的封面编辑入口，也不增加手动裁剪功能。

## 用户流程

1. 用户打开“新建项目”抽屉。
2. 抽屉顶部显示“项目封面”区域，初始展示内置默认封面。
3. 用户可以点击封面或“选择图片”选择一张 PNG、JPEG 或 WebP 图片，单文件不得超过 20 MB。
4. 选择成功后立即显示本地预览，并提供“更换”和“恢复默认”。图片只按展示区域居中覆盖，不修改原始文件，也不进入裁剪步骤。
5. 用户关闭抽屉时，已选择的封面与其他项目草稿一起保留；重新打开抽屉仍显示该预览。
6. 用户创建项目后，自定义封面保存为项目内受管资产，项目元数据记录其资产 ID；项目卡片立即显示该封面。
7. 创建成功后清空整个新建项目草稿，包括封面选择；下次新建重新显示默认封面。

## 数据模型

`ProjectMetadata` 增加可选字段：

```ts
coverAssetId?: string;
```

`ProjectMetadataInput`、`ProjectMetadataPatch`、`ActiveProject` 和渲染层 `Project` 同步支持该字段。字段保持可选，确保旧项目、旧项目包和缺少封面的项目继续正常加载。

自定义封面以现有受管资产保存，并带有：

```ts
metadata: {
  purpose: 'project-cover';
}
```

素材库默认隐藏 `purpose = "project-cover"` 的内部封面资产，项目复制、导出、备份和恢复仍通过现有资产清单保留它。

新建表单草稿持有一个仅存在于当前渲染会话的封面选择对象，其中包含文件名、MIME 类型、文件字节和预览 URL。二进制不写入项目列表状态或项目元数据。

## 创建与持久化

渲染层继续先调用现有 `createProjectContainer` 创建项目容器。项目创建成功且用户选择了自定义封面时：

1. 调用现有 `importAssets`，将图片保存到新项目并标记为 `project-cover`。
2. 从成功结果取得受管资产 ID。
3. 调用 `updateProjectMetadata` 写入 `coverAssetId`。
4. 更新渲染层项目记录和项目卡片封面。

如果封面导入或元数据更新失败，项目仍视为创建成功，使用默认封面，并向用户显示“项目已创建，但封面保存失败，已使用默认封面”。不留下指向不存在资产的 `coverAssetId`。

预览工作区不写磁盘。预览项目可以在当前会话内使用本地 Object URL 显示自定义封面；关闭应用后按现有预览语义丢弃。

## 默认封面

用户提供的图片作为仓库内静态默认资源，使用稳定的应用相对 URL。所有下列情况都显示同一默认封面：

- 新建抽屉尚未选择图片；
- 用户点击“恢复默认”；
- 项目元数据没有 `coverAssetId`；
- 自定义封面资产缺失、读取失败或无法解码；
- 自定义封面保存失败。

默认封面不是每个项目重复导入的受管资产，避免重复存储相同二进制。

## 封面读取与展示

项目列表对带有 `coverAssetId` 的项目调用现有 `readAsset` 读取受管字节，并创建短生命周期 Object URL。组件卸载、项目变化或 URL 被替换时释放旧 URL。

封面展示组件的回退链为：

1. 当前会话的自定义预览 URL；
2. 已成功读取的受管封面 URL；
3. 内置默认封面 URL。

抽屉预览和项目卡片均使用 `object-fit: cover`、`object-position: center`。图片加载错误时立即切换为默认封面，避免显示破图。

## 抽屉界面

封面区域位于项目名称之前，以宽幅预览作为抽屉的视觉入口，并沿用现有抽屉的克制、精细风格：

- 默认和自定义封面均显示一致比例的圆角预览；
- 预览覆盖层提供“选择图片”或“更换”操作；
- 已选择自定义图片时显示“恢复默认”；
- 隐藏原生文件输入，但通过有标签的按钮触发；
- 错误文案紧邻封面区域，并通过 `role="alert"` 呈现；
- 键盘用户可以聚焦并触发选择、替换和恢复操作。

文件选择只接受 `image/png`、`image/jpeg` 和 `image/webp`。空文件、不匹配的 MIME 类型和超过 20 MB 的文件在读取预览前被拒绝，且不会覆盖当前有效选择。

## 状态生命周期

- 取消、点击遮罩或按 Escape 关闭抽屉：保留封面草稿。
- 重新打开抽屉：继续显示上次选择。
- 恢复默认：释放当前 Object URL，并清除自定义封面数据。
- 选择另一张图片：验证新图片成功后释放旧 Object URL。
- 创建成功：释放 Object URL 并重置整个新建项目草稿。
- 创建失败：保留当前封面和表单草稿，允许重试。

## 兼容性与边界

- 不迁移旧项目；缺少 `coverAssetId` 即代表使用默认封面。
- 不支持 SVG、GIF、HEIC、PDF 或 PSD 作为项目封面。
- 不支持远程 URL、素材库选择或跨项目引用。
- 不支持手动裁剪、焦点坐标或缩放持久化。
- 不增加项目详情页的封面编辑功能。
- 只读工作区仍不能创建持久项目，行为与当前实现一致。

## 测试与验收

单元测试覆盖：

- 新建表单初始显示默认封面；
- 合法图片显示自定义预览；
- 非法类型和超大文件被拒绝且不替换当前选择；
- “恢复默认”清除自定义封面；
- 关闭抽屉保留封面草稿，创建成功清空草稿；
- 项目元数据创建、更新和旧数据加载兼容 `coverAssetId`；
- 素材库隐藏 `project-cover` 资产；
- 项目卡片读取自定义封面并在失败时回退默认封面；
- 创建项目后依次导入封面、更新元数据；失败时仍创建项目并回退默认封面。

集成测试覆盖项目重启后仍能从 `coverAssetId` 读取同一受管封面，以及复制、导出和恢复不丢失封面关联。

浏览器测试覆盖选择封面、预览、恢复默认、取消后重开、创建项目和项目卡片展示的完整流程，并检查标准与窄窗口下没有横向溢出。
