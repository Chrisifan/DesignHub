# 画布所选候选导出设计

## 目标

移除画布顶部的导出入口，在右侧上下文工具栏提供直接导出所选候选稿的操作，并修复不可见的定稿图标。

## 交互

- 顶部工具栏不再显示导出按钮。
- 右侧工具栏在定稿按钮上方显示导出按钮。
- 导出与定稿都以当前 `selectedCandidateId` 为唯一选择来源；没有选中候选时禁用。
- 导出按钮直接以 PNG 写出当前所选候选，不进入交付页，也不要求先定稿。
- 用户取消系统保存对话框时不显示错误；成功后提示输出路径；异常时提示导出失败。
- 定稿按钮使用仓库中实际存在的 `circle-check` 图标，并与导出按钮共享清晰的启用、禁用状态。

## 数据流

Workbench 根据 `selectedCandidateId` 在现有任务结果中解析 `TaskCandidate`，选取 `sceneAssetId`，缺失时回退到第一个 `assetId`。导出时创建一个与当前文档尺寸一致、只含该图片资产的临时 `DesignScene`，然后通过桌面桥 `exportDocument` 以 PNG 导出。临时 scene 不保存、不提交 revision，也不改变候选或正式画布状态。

## 验证

- 顶部不存在导出按钮。
- 右侧导出按钮未选择候选时禁用，选择后启用。
- 导出请求包含当前工作区、项目、文档、PNG 格式和所选候选资产。
- 定稿按钮渲染 `circle-check`，启用状态具备可见的高对比样式。
