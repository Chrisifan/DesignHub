# 原图比例生成尺寸修复

## 目标

让项目对话框的“原图”比例使用当前唯一选中 `ProjectDesign` 的真实尺寸，而不是复用首次对话冻结的默认 `1080 × 1440`。固定比例 `3:4`、`1:1`、`16:9` 的行为保持不变。

## 行为

- 选择“原图”且画布上恰好选中一张设计图时，本次生成使用该设计图的 `width` 和 `height`。
- 没有唯一选中设计图时，继续使用分析任务的画布尺寸作为兼容回退。
- 本次解析出的原图尺寸随生成提交一起传入主进程，并固化到生成任务的 `designContext.canvas`。
- 已提交任务及候选重试继续使用任务快照，不读取之后的画布选择或项目设置。
- 固定比例始终解析为现有预设尺寸，不受原图尺寸参数影响。

## 边界与校验

- `ProjectCanvas` 负责从持久化选择状态和当前设计列表解析唯一选中设计。
- `Studio` 和桌面桥接只转发结构化尺寸，不读取图片字节。
- IPC 只接受 1 到 20000 之间的整数宽高。
- `AgentTaskService` 仅在 `generationRatio === "original"` 时使用显式尺寸，否则忽略它并使用固定预设。
- 不修改 `ProjectMetadata`、`ProjectDesign`、画布布局或历史任务 schema。

## 验证

- 组件测试证明选择一张非 3:4 图片后，“原图”生成提交携带其真实尺寸。
- 服务测试证明显式原图尺寸覆盖旧对话画布尺寸。
- 服务测试证明固定比例仍使用固定尺寸。
- IPC 测试拒绝无效、超限或非整数尺寸。
- 类型检查、focused tests、unit、integration 和 build 通过。
