# Multi-document design projects

> **Superseded for V1 by [ADR 0029](0029-project-canvas-v1-baseline.md).** Retained as historical context; ProjectCanvas is the only V1 project editing surface.

One design project will group multiple related design documents under a shared asset context and project timeline. Each document keeps its own revision and attribution history, which supports campaign-sized work without conflating independent output formats or their final versions.
