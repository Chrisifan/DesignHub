# Conversation and tools share revision history

> **Superseded for V1 by [ADR 0029](0029-project-canvas-v1-baseline.md).** Retained as historical context; both paths now append project-level designs.

Designer-driven changes and direct image-processing tools will both create revisions in one document history. A tool inspector provides deterministic controls while conversation interprets broader intent, so users do not have two incompatible editing paths or unexplained overwrites.
