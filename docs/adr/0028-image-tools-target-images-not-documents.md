# ADR 0028: 图像工具直接作用于图片

## 状态

已接受

## 决策

九个画布图像工具以及四个批量图像工具的用户模型统一为“输入图片 → 配置工具 → 生成图片结果”。用户不需要创建、选择或理解设计文档，也不需要进入复杂的图层编辑器才能处理图片。

项目内工具从当前项目的受管图片或设计稿取得输入；需要区域的工具只要求图片选区；本地转换和 provider 处理都产生独立结果，默认不覆盖原图。旧版本中的 `documentId`、revision 文件和 scene 字段保留用于兼容已有项目和历史任务，但它们不是新图片处理任务的前置条件，也不应出现在用户提示中。

## 原因

产品定位是图片创作与处理，而不是在线图片编辑器。强制“先创建文档”会让只有图片结果的项目无法使用工具，并把内部持久化结构错误地暴露给用户。

## 影响

- 图片工具入口可以从项目图片列表直接打开。
- 没有旧文档字段的新项目仍可执行图片处理。
- 结果确认、导出和导入素材库继续保留；需要历史兼容时由内部存储适配层处理。
