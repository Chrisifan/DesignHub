# Revision-level creative attribution

> **Superseded for V1 by [ADR 0029](0029-project-canvas-v1-baseline.md).** Retained as historical context; V1 stores the project designer snapshot without revision-level contribution records.

Designer attribution will be stored as immutable contribution records tied to specific design revisions and roles, then carried in project and export metadata. Names will not be visibly burned into output images by default, so attribution remains accurate across variants and practical across delivery channels.
